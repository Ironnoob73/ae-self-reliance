# Sunlight Resonance Generator

The **Sunlight Resonance Generator** is a block that generates power using sunlight. It requires an unobstructed view above it in order to function.

By default it makes 5 AE/t per Skylight level. for instance, a Skylight level of 15 produces 75 AE/t.

## Upgrade

<ItemLink id="ae2:energy_card" /> increases the efficiency of the chamber by +50%, for a max of +150%.
